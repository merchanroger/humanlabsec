# LABS — Réplica pública para GitHub Pages

Proyecto estático basado en el ZIP entregado, adaptado para replicar la experiencia pública de LABS (Inicio, Nosotros, Notas de salud y Contactos), sin implementar autenticación del Login.

## Archivos
- `index.html` — estructura y contenido.
- `styles.css` — estilos responsive.
- `script.js` — navegación móvil, carrusel, notas, sedes, formulario, idioma y cookies.
- `assets/` — imágenes locales del proyecto.

## GitHub Pages
No requiere build ni servidor. Publicar el contenido de la carpeta raíz como sitio estático.
